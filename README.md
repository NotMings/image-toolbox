# Image Toolbox
图片工具箱是一个简单的图像处理工具，它目前提供了图像格式转换、压缩图片、重命名图片以及暂停/继续处理的功能，后续会添加新的功能。

## 功能
### 图片格式转换
可以转换图片的格式。例如，将png格式的图片转换为jpeg格式的图片。

### 图片压缩
可以压缩图片到指定的大小近似值。

注意，并不是所有的图片都可以压缩到指定的大小，因为图片的压缩率是有限的。
当无法压缩到指定大小时，会裁剪图片避免出现图像失真的情况。

### 重命名图片
可以重命名图片，重命名后的图片会按照指定的规则进行命名。

### 暂停与继续
处理过程中可以点击“暂停”按钮暂停任务，此时按钮会变为“继续”，点击后从暂停的位置继续处理。

## 交互提示
- 把透明图片（PNG/WebP 等）转换为 JPEG 时，会弹窗询问：合成白色背景、跳过该图片或取消处理。
- 输出文件与已有文件或本批次其他输出重名时，会弹窗询问：覆盖文件、自动加序号、自定义前缀或取消处理。

## 注意事项
程序的输出图片如果与输出文件夹中已有文件重名，会弹窗询问处理方式；同一批次处理中出现重名（例如递归载入不同子目录的同名图片）也会询问。为了减少确认操作，建议使用空的输出文件夹。

在转换或压缩图像时，请确保您有权修改原始文件。请尊重版权法规。
